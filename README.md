🛑 Boycott Checker Web App
#FreePalestine – Check if a product or brand is associated with Israel before you buy.

This is a lightweight, responsive web-based tool that allows users to search for products or companies and determine if they are affiliated with Israel, supporting the global movement for ethical consumer choices.


🧠 How It Works
Users enter a product name into the search bar.

The app checks a curated database of companies and products tied to Israel or its affiliates.

A clear result is returned: either the product is associated with Israel (⚠️ Warning) or not (✅ Safe).
